# 实现边界

最新增量为 [SSR Compute 后端](scene-compute-backend.md)：可选 RandomWrite 追踪与最小深度缩减，默认仍为 raster，含能力回退、严格模式和私有 kernel 生命周期。完整 t15/D3D11 Player 的 93 项新增计算检查成立；全套 1997 项接受，97×73 至 1025×769 三种尺寸同输入反射／置信度逐像素一致。修正了历史采样的边界判定：旧 1904 项中 1900 项报告记录相同，四项正对照数量小幅改变且原断言仍成立，具体数值与保留失败见 [渲染记录](rendering.md)。普通离屏角色摄影完成；没有据此声称性能提升或新增动态窗口验收。

前一场景增量为 [SceneReflectionResolve](scene-reflection-resolve.md)：Planar 优先并跳过对应 SSR、失败回退 Probe、全分辨率法线差分扭曲及一次材质响应合成。完整 t15/D3D11 Player 的 52 项新增 GPU／输入／生命周期检查成立；全套 1904 项合成和角色自检接受，前版 1852 项完整报告记录相同。六面 Probe 世界方向与 HDR 解码、切线 X／Y 和镜像变换经过独立数值对照；普通离屏角色摄影完成。默认关闭，要求宿主显式去掉接收面主材质的旧间接镜面项，不自动改写材质。完整角色廉价捕获、SSR 粗糙度过滤、多 Probe 调度和移动性能仍未完成。

前一场景增量为 [PlanarReflection](planar-reflection.md)：显式简化 Forward 捕获、画外发光网格、oblique 裁剪、独立区域覆盖与接收面深度、粗糙度 mip。该阶段完整 t15/D3D11 Player 的 40 项新增平面反射 GPU／蒙皮／生命周期检查成立，上一版 1812 项完整报告记录相同。组件默认关闭，生成夹具的主图逐像素保持相同；普通离屏角色摄影完成。统一消费者现见上段，完整角色材质适配仍待完成。

更早场景增量为可选 [ScreenSpaceReflection](screen-space-reflection.md)：Hi-Z 屏幕空间追踪、排除角色的场景颜色／深度历史、重投影与遮挡变化拒绝、HDR 加法接入。该阶段完整 t15/D3D11 Player 的 31 项新增 SSR GPU／生命周期检查成立，上一版全部 1781 项报告记录逐项相同；默认 128 步生成场景得到 733 个有效反射像素，普通离屏角色摄影完成。组件与管线引用默认不启用，默认摄影路径保留。SSR 粗糙度过滤和移动性能仍未完成；上述场景阶段均未重新运行下方 55 帧窗口探针。

前一场景增量为可选 [SceneDepthData](scene-depth-data.md)：独立几何法线／SSR 资格／线性深度，以及保留奇数边缘的最小深度层级。该阶段完整 t15/D3D11 Player 的 60 项新增 GPU 与生命周期检查成立，上一版全部 1721 项报告记录逐项相同；普通离屏角色摄影完成。组件不自动挂载到摄影相机，其反射消费者现见上段。

框架技术采纳清单见 [framework-techniques.md](framework-techniques.md)。前期新增可选自然风、TAA 表面分类和自制网格顶点编码接口，均位于工具包，不依赖摄影 UI。该阶段完整 t15/D3D11 Player 构建完成；新增 53 项风场／真实动态链检查、26 项 TAA GPU／遮挡／生命周期检查及 9 项顶点编码检查成立，旧 1633 项自检的完整报告记录保持相同。普通离屏摄影可输出。2026-09-12 同一 Player 在可见窗口完成 55 帧角色探针，六组静态恢复逐像素相同，暂停绕拍姿态保持、动画恢复成立；隐藏启动复现零绘制命令，定位为本机启动条件限制，未修改生产渲染逻辑。移动端后端与观众系统等仍未实现，不能记为完整框架追平。

## 已有实现

按 QualiArts PPT 第 130 页与 CEDEC 管线 PDF 第 29 页，工具包已有默认关闭的相机局部 Sphere Fog。透视／正交／偏移投影、实际深度遮挡和隔离控制经过完整 t15 / D3D11 Player 验证；独立积分模型、使用入口与历史隐藏启动失败记录见 [渲染说明](rendering.md)。这不等于两份资料或博客的完整实现。

角色渲染增量包含平滑法线描边、stencil 限定的前发覆盖、Layer 双区域采样、剧情光照参数连接、有色边缘光及点光/聚光控制；见 [角色渲染与验证](rendering.md)。原版 shader 研究入口仍有兼容性限制，不属于已完成的原版画面重放。

已修正角色渲染文章第 3.7 节对应的脸部三角区输入：头部基底现在包含左右反射，强侧光下缺失的背光脸颊亮区恢复。实际 GPU 自检能拒绝旧实现；真实模型左右侧光、普通摄影和剧情检查已执行。此次是 C# 程序集增量验证，未执行新的完整 Editor 构建，也未证明完整博客效果追平。

私有原生 D3D11 参考已将一个原始眼高光绘制重放到与截帧逐位相同的颜色、辅助数据及深度缓冲，并验证重复和缺贴图/跳过绘制控制。范围仅限该单帧绘制；本地复现仍有残差，完整原版场景、其他材质和 Unity bundle 兼容性尚未据此验证。

固定捕获支持显式私有相机矩阵及材质 UV 输入。已通过实际 GPU 顶点对照纠正旧相机提取的正交基假设错误，眼高光屏幕位置最大残差降至 0.00166 像素，不再依赖整数图像平移；颜色与边界仍未逐像素追平。普通摄影/剧情不启用该覆盖；本轮只有私有 C# 程序集重编译验证，尚非新的完整 Editor 构建。

已移除全局强制各向异性过滤，改为尊重贴图设置。一个眼高光原生绘制对照确认：此前强制模式改变了实际 GPU sampler；修正后同格式、匹配底色的亮度 MAE 从 0.019688 降至 0.000178，覆盖 IoU=1。此结论不覆盖其他材质，也不消除与原始 HDR 格式的量化差异。

外围使用入口 `studio.py` 提供 configure、doctor、catalog、build、photo、story；预检文件与调用既有流程，不提供素材、格式转换或新的运行时功能。

单个主要角色装配、摄影 UI、动作与面部播放、视线、毛发/衣物/身体动态、部分跨角色换装、角色着色和后处理；转换后剧情时间线驱动动作、表情、配音、部分镜头、背景和效果。存在还原差异，不保证全角色、全服装、全部剧情或 Live 兼容。

## 验证与发布边界

附加点光/聚光的合成已补上主光乘色、风格化角度响应以及反射颜色的视角/粗糙度项，继续保留头发和材质遮罩。同引擎完整构建的旧 shader 被 37 项新增 GPU 用例拒绝，最终版全部 211 项实际自检通过；普通摄影、剧情及每版 48 张模型探针完成。未启用附加光的固定画面五项渲染缓冲与旧版逐位相同，静态参数恢复均为零变动像素。强点光下皮肤仍有高亮裁切，尚不能宣布整体博客效果追平。

天光现按材质的漫反射响应加权，不再给金属区域叠加完整漫反射天光；脸部和眼睛保留各自的非金属分支。同引擎完整构建的旧 shader 在 24 项新增 GPU 检查中失败，修正版全部 163 项自检通过；普通摄影、剧情及每版 41 张真实模型探针完成。跨进程全身探针存在姿势差异，已保留被拒绝的比较，另用固定几何核对：GI=0 时五项渲染缓冲不变，启用 GI 后材质响应改变，辅助数据不变。整体博客效果仍未全部验收。

RampAdd 的镜面反射调制已修正，不再重复乘上仅属于漫反射的 `(1-A)`；A=1 时保留贴图指定的染色反射，无 RampAdd 变体不变。同引擎完整构建的旧 shader 被新增检查中的 8 项镜面反射用例拒绝，新版全部 136 项实际 GPU 自检通过。普通摄影、剧情和 38 张模型探针完成；固定模型的漫反射诊断逐位不变、镜面反射诊断发生变化。该固定服装下最终画面变化较小，完整博客效果仍待验收。

发丝/发饰高光分区已修正：发丝保留 HighlightMap，常规镜面反射限定在发饰 UV 区域，附加灯同步遵守遮罩，精确边界不再误分。已完成同引擎旧/新 shader 的完整 Player 构建；新增实际 GPU 检查能拒绝旧代码的 8 项错误，新版全部 96 项自检通过。普通摄影、剧情及每版 38 张真实模型探针已执行，状态恢复均为零变动像素；固定镜头的 HDR 改动经颜色 pass 诊断限定在头发绘制。此结论仅覆盖该分区修正，整体博客效果仍待验收。

皮肤饱和度的 Shade.A 遮罩与线性亮度修正已完成 t15 的实际 Player 构建和同引擎旧代码对照。GPU 自检拒绝旧实现的 14 项皮肤错误，修正后全部 78 项通过；真实模型的脸部/身体响应、38 张渲染探针、普通摄影及剧情检查点已检查。默认固定画面的五项渲染缓冲与旧饱和度代码逐位相同。完整博客渲染效果仍未全部验收，源码哈希和这些局部检查不能代替整体验收。

发布整理时撤回了工具化的动作选择、调度和导出变更。后续渲染增量在独立修订清单中记录，原冻结 SHA-256 保留为历史证据；没有借本轮渲染工作重新引入动作/物理/剧情调度改写。源码检查只忽略 Git 的 CRLF/LF 转换，不比较运行结果。

构建证明能够编译和链接，不证明头颈、毛发、过渡、渲染或物理与原游戏一致。历史“帧不全黑”检查不属于画面一致性验收。物理有历史状态，不同 GPU、数据、帧时序和引擎会影响输出。
