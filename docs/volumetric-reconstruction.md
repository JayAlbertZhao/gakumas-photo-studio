# 低分辨率体积光积分

`VolumetricLightingSettings.resolution` 默认为 `Full`，保留原有完整分辨率积分路径。`Half`／`Quarter` 分别把积分附件宽高除以 2／4 并向上取整。独立桌面整图、实际相机与原生生产消费链已执行，完整舞台和移动成本仍需单独验收。

```csharp
var settings = new VolumetricLightingSettings {
    enabled = true,
    resolution = VolumetricResolution.Half,
    lights = authoredSpotLights
};
// 相机、深度、介质与动态遮挡输入沿用 VolumetricLightingRenderer。
```

## 绘制与重建

先从完整当前深度生成缩减 min／max 眼深度范围，覆盖每个低分辨率像素实际重叠的全部完整像素，包括奇数边缘。无效深度、受保护像素或不受影响的天空使该低像素范围无效。原有积分器随后在真正缩小的目标上执行，以范围最小眼深度结束低分辨率相机射线；阴影图仍由本帧真实 caster 产生，不缩小或缓存旧阴影。

完整分辨率 R8 遮罩检查上采样的四个正权重 tap：深度范围混杂、与完整深度不相容，或低分辨率散射对比超过阈值时，标记为重新积分。先为安全像素插值散射，其它像素写零；随后每个灯仅对标记像素执行完整分辨率积分。拒绝分支在灯光／介质积分之前，不能用全图积分后混合冒充省下积分工作。最终透射在完整当前深度解析计算一次，不跨不透明边缘插值消光。

完整像素位于低像素采样中心覆盖范围之外时，也重新积分，不以 Clamp 边缘外推代替另一条相机射线。边缘缺少一侧样本，单靠现有样本颜色差无法发现该方向的变化；正交相机经过介质边界时尤其明显。

采样位置先以整数像素中心比值计算商和余数，再转换为插值小数。恰好对齐的 tap 权重保持精确零，避免浮点 reciprocal／FMA 残差让本来不参与的邻居触发重算条件。

默认深度容差为 `0.005 + eyeDepth * 0.002` 世界单位；散射对比容差为每通道 `0.001 + localMaximum * 0.02`。这些是独立质量参数，不是原文公布的公式。容差决定近似区域和重算区域，不能保证所有极细光束、锐利体积阴影和极端相函数都有固定误差上界；需要完整精度时选择 Full。

## 输出与资源

`frame.scattering` 和 `frame.color` 仍为完整尺寸，散射 alpha 为零，HDR alpha 精确保留输入。缩减模式另借出 `lowResolutionScattering`、`depthRange` 和 `reconstructionMask`，分别为低尺寸 RGBAFloat、低尺寸 RGFloat、完整尺寸 R8。Full 模式这些字段为 null。任意借用目标丢失、下一次调用、失败／关闭／Dispose 均使旧帧失效。

`reconstruction.maximumTargetMiB` 默认 512，分配前检查模块自身颜色／散射／引导目标，不包含输入和阴影。两张完整 RGBAFloat 仍保留，缩减模式增加低尺寸散射／深度范围和完整 R8 遮罩，目标内存并不比 Full 更少。`TargetBytes` 明确报告这部分预算。`ReintegrationDrawCalls` 是重新积分的提交次数，不能当作实际重算像素数；遮罩可供宿主诊断。

缺失格式、Float 混合能力或资源失败时返回失败、释放自有结果并报告原因，调用者保留当前 HDR。核心没有场景搜索、全局深度猜读、截图输入或计时器。基础介质、光源、深度／保护、相机与透明层契约见 [体积光](volumetric-lighting.md)。

## 来源与边界

实际 Player 覆盖两种缩减尺寸、两盏彩色灯、动态 caster／PCF、奇数和单像素尺寸、三种 HDR、透视／正交／偏轴／移动相机、遮挡／保护、别名／目标丢失／预算与默认恢复。独立 2048 步世界空间参考的最大 RGB 差为 0.003661；另在实际相机原生附件上用 4096 步参考检查完整 54524 像素，两个最终 HDR 最大差为 0.0011581 和 0.0008116。遮罩精确，完整 HDR alpha 保留。过程及失败记录见 [渲染记录](rendering.md)。

小尺寸高对比相机样例的重新积分比例为 4194／6305 和 6233／6305，后一例几乎全部重算。相同无阴影视角在 171×117、342×234 时，散射函数的候选像素调用数（低尺寸像素数＋重算遮罩数）分别为 19781／20007、54815／80028。它们不等于总积分步数，更不证明 GPU 加速；缩减分支增加引导绘制和内存，选择 Full 可能更合适。

PDF15／30／31 描述低分辨率重特效和上采样，PPT131 描述聚光灯内部的动态遮挡，没有公开这些重建公式。本实现复用仓库自身积分模型，不附带 VLB／HDRP／原版代码。不同分辨率共享同一个自有 HLSL 积分函数。

P09 的几何透明、连续体积和镜头光学仍需显式联合调度。当前只为连续体积增加可选缩减工作目标，不完成逐透明层输运、不恢复不存在的深度，也未测移动 GPU 帧时、带宽或整体舞台画质。原文的目标仍保留，不能从局部附件尺寸推导完整进度。
